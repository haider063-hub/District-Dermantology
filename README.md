# District Dermatology

Premium multipage marketing site for [District Dermatology](https://www.districtderm.com/) (McLean & Vienna, VA).

## Stack

- Next.js (App Router) + TypeScript
- CSS Modules + design tokens (`#F5F9F9`, `#36CDD0`)
- Fraunces + Manrope

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run start` — serve production build
